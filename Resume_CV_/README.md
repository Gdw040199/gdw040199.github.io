# Dawei Guan - Research Internship CV

This CV adapts the supplied TLC resume template. The template credits [gobborg](https://github.com/gobborg) and [Timmy Chan](https://github.com/TimmyChan); its original section layout and styling have been adapted for this CV.

The main source is `resume.tex`, with education in `sections/education.tex`, research entries in `sections/project.tex`, and skills in `sections/skills.tex`. Project thumbnails are in `images/`.

Compile with `latexmk -cd -pdf resume.tex` from this directory. The published PDF is copied to `files/Dawei_Guan_CV.pdf` and linked from the homepage.

The skills list reflects tools documented in related research environments. No unverified awards or work history are included.
