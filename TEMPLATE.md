# Template provenance

This homepage adapts the layout and styles of [Yiming Huang's homepage](https://yh2371.github.io/), using the source at [yh2371/yh2371.github.io](https://github.com/yh2371/yh2371.github.io), commit `37c4aa398ff858069739d5b854b267d52ab9a386`.

The main reference files are `_layouts/default.html` and `style.scss`. The template's MIT license is retained in `LICENSE`. The reference template credits [Jon Barron](https://jonbarron.info/) and [Leonid Keselman](https://leonidk.com/).

Personal information and the four images were migrated from [Gdw040199/gdw040199.github.io](https://github.com/Gdw040199/gdw040199.github.io), commit `6238b4ea7368d842adcc5a766042ee7ab741261e`.

Changes include Dawei Guan's profile, publications, education, news, and acknowledgement; responsive layouts and readable type; and storing repeated content in `_data` YAML files. The reference author's analytics, visitor tracking, personal media, research projects, and other personal content are not included.

The research summaries are concise paraphrases of the respective [FlowCoMotion](https://arxiv.org/abs/2604.11083), [DaptDiffusion](https://link.springer.com/article/10.1007/s10489-025-06673-1), and [VariGAN](https://www.mdpi.com/1424-8220/25/9/2671) abstracts. They describe the methods without adding numerical results or acceptance claims.

Lato Regular, Bold, and Italic are self-hosted from Google Fonts. The font's SIL Open Font License is included in `fonts/lato/OFL.txt`. The avatar greeting is implemented with text and a wave emoji; the original profile illustration is unchanged.
